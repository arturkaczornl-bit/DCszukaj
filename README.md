# DcSearch

DcSearch to program do wyszukiwania plików w hubach Direct Connect.

## Windows 10

Pobierz instalator **[DcSearch-Windows10-Setup.exe](https://github.com/arturkaczornl-bit/DCszukaj/releases/latest/download/DcSearch-Windows10-Setup.exe)**, uruchom go i postępuj zgodnie z instrukcjami. Instalator jest przeznaczony dla Windows 10 w wersji 32-bit i 64-bit i instaluje program dla bieżącego użytkownika.

**Wymagania:** Windows 10 oraz .NET Framework 4.8 lub nowszy.

> Uwaga: instalator nie jest podpisany cyfrowo; system Windows może wyświetlić ostrzeżenie SmartScreen.
